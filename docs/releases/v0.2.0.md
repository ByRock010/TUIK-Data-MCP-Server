# v0.2.0 — Excel/PDF reading and reproducible table queries

This release extends the public TÜİK MCP server from discovery and CSV access to
bounded Excel/PDF reading, table inspection and reproducible CSV/Excel queries.
All eight tools retain official-source provenance. Python **3.12+** is required;
the server uses the **official MCP Python SDK 1.x**.

## Highlights

- Read verified XLS/XLSX attachments with sheet selection, bilingual headers,
  source notes and bounded rows. Bulletin detail exposes stable file IDs and
  related public CSV datasets; callers explicitly choose the desired source.
- Inspect CSV/Excel column names, observed values, empty counts and conservative
  type hints before constructing a query.
- Project columns, use equality/membership and typed numeric/date/period ranges,
  sort stably and continue with authenticated snapshot-bound cursors through
  `get_tuik_data`. This extends an existing tool; there is no ninth tool.
- Read PDF text by physical page with source metadata and same-page character
  continuation. Scanned/blank pages are explicit; OCR is outside this release.
- Bound downloads, parsing, scans, sorting, caches and response size. Preserve
  raw source strings rather than silently normalizing ambiguous values.
- Include the optional OpenSearch analysis, mapping, metadata crawler, indexer
  and dataset-search backend already accepted on `develop`. Indexed general
  search, cluster CI and independently judged relevance results remain v0.3.0 work.

## Installation and compatibility

Install a release wheel from the GitHub release assets, or the tagged source:

```bash
python -m pip install 'git+https://github.com/ByRock010/TUIK-Data-MCP-Server.git@v0.2.0'
tuik-mcp
```

Existing CSV/Excel calls remain supported. Structured queries and cursors are
optional; see [query examples and budgets](https://github.com/ByRock010/TUIK-Data-MCP-Server/blob/v0.2.0/docs/TABLE_QUERIES.md). Query bounds use
plain decimal notation with an explicit separator when ambiguous. Thousands
separators are not silently removed.

CSV now shares the content-addressed one-hour file snapshot cache with Excel/PDF;
`retrieved_at` records when that snapshot was fetched. A cursor continues the
same retained snapshot, not the latest upstream file. Cursors expire after
15 minutes by default, cannot survive a server restart or move between server
processes, and may be evicted under memory limits. Restart the query after an
expired/invalid cursor; follow `has_more` and `next_cursor` for bounded results.
See the README for `TUIK_*` configuration and optional `.[search]` installation.

## Verification and scope

The [final candidate acceptance report](https://github.com/ByRock010/TUIK-Data-MCP-Server/blob/v0.2.0/docs/verification/v0.2.0-final-2026-10-29.md)
records offline tests, real MCP calls against official sources, CSV/Excel cursor
continuation, remaining live regressions and clean wheel installation. Earlier
incremental evidence remains linked from [VERIFICATION.md](https://github.com/ByRock010/TUIK-Data-MCP-Server/blob/v0.2.0/docs/VERIFICATION.md).
Upstream observations are dated, and real OpenSearch integration is not claimed
by the base release acceptance.

The file-reading milestone's implementation issues and tracking epic are closed.
PRs [#59](https://github.com/ByRock010/TUIK-Data-MCP-Server/pull/59) and
[#60](https://github.com/ByRock010/TUIK-Data-MCP-Server/pull/60) include release
preparation and the accepted #52 query follow-up. Since #52 merged before the
first v0.2.0 tag, it is included in this release and changelog.

PDF table extraction/OCR, semantic retrieval, content indexing, persistent query
sessions and a canonical database are outside this release. Human relevance
judgments and measured search-quality scores remain pending; no results are
inferred from the existence of evaluation tooling.
