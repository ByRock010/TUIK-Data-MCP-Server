## Contract

`get_tuik_data` adds optional `query` and `cursor` inputs, without another tool.
`query={}` opts into complete table pagination. Projection, equality/membership,
inclusive numeric/date/declared-period ranges and stable multi-key sorting preserve
source strings. Every referenced column is validated; conflicting legacy/new
conditions on the same column are rejected. Dates are ISO, numeric ambiguity is
explicit, missing markers stay distinct from zero, and source positions break ties.

Cursor state binds the resource, selected sheet, normalized query/projection/sort,
content hash, extraction/query version and next position. HMAC-SHA256 uses a
per-service random secret. Immutable result-state caches have byte/entry/TTL limits;
TTL is capped by the original file body's remaining lifetime. A later identical
download cannot resurrect an expired cursor. Resume never performs resource lookup
or download, even on cursor errors. Full semantics and budgets:
[`TABLE_QUERIES.md`](../TABLE_QUERIES.md).

## Limits and merge order

- Exact numbers use plain signed decimal notation; grouped numbers, exponent syntax
  and percent suffixes are intentionally rejected. No automatic unit conversions,
  geographic normalization, SQL, arbitrary expressions, OCR or PDF-table queries.
- Cursor scope is the service process, shared by its MCP connections; no cross-process
  persistence. Expired/evicted snapshots require restart, without pinning file bodies.
- The response budget measures indented UTF-8 JSON, not total wire protocol overhead;
  cache budgets measure stored payload bytes, not OS-level RSS. Existing parser
  archive/grid/input limits remain in force.
- PR #59 merged at `d8c358f`. This branch has merged that develop update and keeps

  accepted 0.2.0 scope before #52 merges, or refresh version/changelog/evidence for

## Review follow-up — numeric range operands

Reviewed commit `fdd4142` accepted a `minimum: "1.234"` on an integer-only column
as the decimal 1.234 without an ambiguity error. Range-bound failures also used
messages identifying the value as source-column data. Both were reproduced before
fixing: the new regression file initially reported **8 failed, 7 passed**.

Fixed at `3e4654a5a430ea91c7d6c091cac95e7c5581390a`, after merging `develop`
at `d8c358f` (PR #59). Three-fraction-digit operands now require an explicit
separator unless unambiguous source decimals established that same separator.
Integer-only columns provide no such evidence. Both minimum/maximum and both
dot/comma notation are covered. Explicit separators retain exact decimal semantics;
grouped integers are never guessed. Bad or missing operands identify the range
minimum/maximum separately from actual source-column errors. The real MCP protocol
test also checks rejection and successful explicit resolution.
