# Issue #6 — spreadsheet rows through MCP

Verified on 2026-10-22 (Europe/Istanbul), building on the #9 parsing/cache foundation.

## Design and compatibility

- Public dataflow CSV remains preferred. A bulletin with exportable dataflows returns
  choices; callers choose a `flow:` ID or an explicit bulletin-file ID.
- Verified XLS/XLSX files now return `status: ok` with string rows, exact filters,
  total count, truncation, units, sheet list/selection, table title and source notes.
- Source provenance cites the actual downloaded file and its snapshot retrieval time.
  Existing resource `notes` stays a string; extracted notes use `table_notes`.
- A raw-layout fallback remains visible through `layout` and `warnings`.
- PDF/ZIP behavior remains verified download; CSV fields and exact filtering remain
  compatible. Optional new fields are additive. `sheet` on CSV is an input error.
