## Reproduce the recorded pilot

The input is derived entirely from the committed baseline, preserving its source
strings and timestamps. From the repository root:

```bash
.venv/bin/python - <<'PY'
import json
from pathlib import Path
from tuik_mcp.search.documents import IndexDocument

baseline = json.loads(Path('docs/verification/search-baseline-2026-10-26.json').read_text())
eligible = set(baseline['systems']['literal']['corpus_ids'])
with Path('/tmp/tuik-evaluation-dataflows.jsonl').open('w') as output:
    for item in baseline['catalog']:
        if item['id'] not in eligible:
            continue
        document = IndexDocument(
            id=item['id'], kind='dataset', title=item['title'],
            description=item['description'],
            theme=[item['theme']] if item.get('theme') else [],
            source_url=item['source_url'], formats=item['available_formats'],
            downloadable=True, retrieved_at=item['retrieved_at'],
            indexed_at=baseline['catalog_retrieved_at'],
        )
        output.write(document.model_dump_json() + '\n')
PY
docker compose up -d --wait opensearch
.venv/bin/python scripts/evaluate_search.py collect-index \
  --documents /tmp/tuik-evaluation-dataflows.jsonl --url http://127.0.0.1:9200 \
  --output /tmp/search-variants.json
.venv/bin/python scripts/evaluate_search.py pool \
  --runs docs/verification/search-baseline-2026-10-26.json /tmp/search-variants.json \
  --output /tmp/enlarged-pool.json
.venv/bin/python scripts/evaluate_search.py score --suite /tmp/enlarged-pool.json \
  --runs docs/verification/search-baseline-2026-10-26.json /tmp/search-variants.json \
  --output /tmp/pending-comparison.json
```

The last command must report `pending_judgments`, with undefined κ. Its unjudged
numeric metric fields must not be presented as measured quality. Export judge
sheets from the enlarged pool using the protocol in
[SEARCH_EVALUATION.md](../SEARCH_EVALUATION.md).
