# Guided workflows over MCP stdio

On 26 November 2026, two separate clients launched the local server and
queried the public TÜİK portal at the default request pace. The tasks follow
F01 and L05 from the [frozen benchmark](../issue-85/tasks.json). The F01 cutoff
was advanced to the test date to verify freshness. Each client selected the
latest eligible bulletin from returned titles and publication dates and opened
its returned ID. For L05, each followed the documented unsupported-case
guidance and checked that the published 2025 alternative links a province-level
unemployment table. No monthly provincial value was produced.

The Python client consumed only text tool results and used the README route
without requesting prompts. The TypeScript client listed the prompts and read
both relevant templates before using the tools. These were deterministic
protocol checks with no model or graphical client involved.
