   test indices and use recorded TÜİK adapters instead of live upstream requests.
5. Document local reproduction and retain JUnit output on GitHub test failures.
   Require an actual green PR service-container run before declaring #19 complete.

`İstanbul'un`, `İstanbul’un`, `istanbul`, `nufus`, `TÜFE`, `TUFE` and `tufe`.
The consumer-price abbreviation never matches the producer-price document.
Combined filters include a bulletin at `23:59:59Z` on the upper publication date;
metadata-only, non-downloadable-only and empty-match paths are checked too.
Fallback tests use both unset configuration and an actual 404 from a UUID alias
that does not exist in the running cluster. They verify that datasets use literal
matching, bulletins use the portal, ignored theme filters are warned and unknown
filtered totals remain null. No real TÜİK traffic is made.

The other three pre-existing marked tests cover strict mapping validation,
fixture crawler → rebuild/update/alias swap and long-body highlights. The CI job
runs all marked tests, so later additions are included without a filename list.
It uploads `opensearch-results-<run>-<attempt>` for 14 days, including failed tests.
