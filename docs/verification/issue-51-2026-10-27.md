## Offline, against recorded official files

The profiles below come from the recorded TÜİK corpus (`tests/fixtures/README.md`:
unmodified official files retrieved 2026-10-13/18, SHA-256s in `files/manifest.json`)
and the recorded `DF_ALTINSIZ_DTH+V1.0` CSV export.

- **CSV dataflow** (`flow:DF_ALTINSIZ_DTH+V1.0`): 16 columns, 3/3 rows, `complete`.
  `Gözlem Değeri` → `number`, `decimal_separator: ","`; its values stay
  `98,4622068329301` etc. `Zaman (2015-01)` and `Temel Dönem/Yıl (2015)` → `period`.
  Five all-empty columns → `unknown` with `empty: 3`. Filtering
  `get_tuik_data` with `Zaman (2015-01) = 2015-02` returns one row with the same
  `snapshot_id` and `retrieved_at`; one CSV download and one parse serve two
  inspections plus the query.
- **XLS labour-basic**: sheet `Tablo`, 37 columns, 260/260 rows, unit, title and notes
  kept. Duplicate-looking headers keep exact keys such as
  `İşgücü Labour force [column 4]`. `Yıllar - Years [column 1]` → `period`
  (22 distinct); a returned `column_2` month label works as a `get_tuik_data` filter.
- **XLS population**: every column printing `-` reports `placeholders: {"-": 30}`,
  stays `number`, and lists `-` as an observed value; nothing is read as zero.
- **XLSX CPI basket**: `Kod Code` → `mixed` because zero-padded identifiers (`01`)
  coexist with `10`; `distinct_count: 752` is exact while `values_complete` is false
  for `max_values: 200`.
- Raw-layout workbooks keep their warnings; unknown sheet → `invalid_input`,
  unknown `columns` → `invalid_columns`, duplicate CSV headers → `malformed_response`,
  PDF → `download_available`, bulletin with dataflows → `related_datasets` without
  downloading files. Partial scans (`inspect_max_rows`) and capped distinct tracking
  never report exact domains; output budgets shrink values, then columns, with warnings.

## Review fixes (PR #57)

- `values_complete` now also requires a complete scan: a row-capped profile whose
  observed values all fit `max_values` no longer claims an exhaustive list.
- The output budget is measured as UTF-8 bytes of the indented JSON FastMCP sends
  (`pydantic_core.to_json(..., indent=2)`); multibyte text (190 × `ş` per value)
  stays within 8,192 bytes, and a single 9,000-character header profile is omitted
  with a warning instead of exceeding the limit. Columns are fitted by binary search.
- `scripts/live_smoke.py` runs inspect → exact-filter `get_tuik_data` for one CSV
  dataflow and one bulletin Excel table, asserting the same `snapshot_id`,
  `source_url` and `retrieved_at` (and matching counts for complete scans).
  `tests/test_live.py` checks all eight tool names. The step itself is exercised
  offline against the recorded CSV and `labour-basic.xls`.
