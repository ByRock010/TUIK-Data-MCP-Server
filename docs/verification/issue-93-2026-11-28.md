## Acceptance criteria

- **A six-slide Turkish briefing with real validated values and sources, plus
  an English example.**
  - The briefing spec gives six slides in this order: title and key messages, `Tablo`, `Grafik`, `Bulgular`, `Yöntem ve sınırlılıklar`, `Kaynaklar`.
  - Every value is the report's own display text.
  - The English deck uses English labels (`Methods and limitations`, `Source: TurkStat (TÜİK)`).
  - Tests: `test_turkish_briefing_is_editable_and_matches_the_report`, `test_english_labels_and_a_deterministic_deck`.
- **Native, editable line and bar charts with embedded data; text and tables
  editable.**
  - Line charts are `LINE_MARKERS` and bar charts `COLUMN_CLUSTERED`. Each has an embedded workbook, and gaps stay empty.
  - Tables are native tables and all text is in text boxes.
  - Tests: the same tests, plus `test_drafts_are_marked_on_every_slide_and_long_content_continues` for bars.
- **Compact source/period/unit note on every analytical slide; full citations
  in speaker notes.**
  - The note reads `Kaynak: TÜİK · <resource> · Dönem: … · Birim: … · Erişim: …`.
  - Speaker notes carry the official URL, observation or calculation IDs, formulas, release date, retrieval time and snapshot, and the report ID.
- **Read-back against the report and missing asset references.**
  - `verify` runs on every render. It checks table cells, chart categories, series names and values, and the embedded workbooks. It resolves every internal relationship and refuses any external one.
  - `test_read_back_rejects_a_changed_cell_or_point_and_external_targets` changes a cell, a chart point and a hyperlink; each is refused.
- **Rendering and visual inspection.**
  - All slides were rendered with `soffice --headless --convert-to pdf` and `pdftoppm`, then inspected for three decks:
    - Turkish, six slides;
    - English, six slides;
    - English draft with long text: eight slides, with continued key messages and a continued table.
  - Checked:
    - Turkish glyphs (İ, ı, ş, ğ, ü, ö, ç), with no tofu;
    - long subtitles and long bullets wrap;
    - legends sit at the bottom, unclipped;
    - no overlap between body and footer;
    - the minimum font size is 12 pt everywhere, enforced in tests.
  - A spilled methods bullet and a wrapping value column found during inspection were fixed before commit.
- **Opening and editing in a named editor.**
  - LibreOffice Impress 24.2.7.2 opened the deck through its UNO API. A slide title, a table cell and a chart value were edited and saved back to PPTX, and the edits read back with python-pptx.
  - Known difference: LibreOffice drops the embedded chart workbook on re-save but keeps the cached values.
  - Microsoft PowerPoint was not available.
- **Optional dependency; other tools unaffected; delivered through #88.**
  - `python-pptx` is in the `pptx-out` extra and imported only for `pptx: true`.
  - `test_missing_extra_fails_only_the_deck_request` shows that `pptx_unavailable` is returned for that request only, and that the same report without `pptx` still builds.
  - The deck is `report.pptx` in the report artifact, with its MIME type, size and SHA-256 in the manifest.
