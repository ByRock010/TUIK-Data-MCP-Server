  long text and multi-page tables rendered and visually verified.**
  - Headings use `Title`/`Heading 1`/`Heading 2`.
  - Every table header row has `w:tblHeader`, and data rows have `w:cantSplit`.
  - A page break precedes Methods.

  - A long English draft (seven summary findings, an eleven-row KPI table and a fifteen-row chart table) rendered to PDF shows the header repeating on pages 2 and 3, wrapped long text and the page break.
- **Template content constrained and source text escaped; unsupported features
  fail clearly.**
  - `docx_template` accepts five placeholders. Unknown placeholders, unmatched braces, braces in `organization`, control characters and extra keys are refused with messages.
  - Hostile host text (`<w:t>`, `{title}`, a Markdown link, `HYPERLINK`, `PAGE`) stays literal, with no new field or link.
  - Tests: `test_template_placeholders_are_fixed_and_text_stays_plain`, `test_read_back_rejects_changed_cells_foreign_links_and_fields`.
- **Optional dependency and bundle retrieval like the other renderers.**
  - The `docx-out` extra is imported only for `docx: true`. Without it, the request fails with `docx_unavailable`; other calls work.
  - The file is `report.docx` in the report artifact, with its MIME type, size and SHA-256 in the manifest.
  - Test: `test_rejected_reports_have_no_brief_and_the_extra_is_optional`.
