## Acceptance criteria

- **Pinned inputs, mixed retrieval times, retained sources within quota.**
  - Each manifest input records page, verified download URL, format, `retrieved_at`, publication date, SHA-256, size and the exact selection.
  - Inputs with different retrieval times set `retrieval_times_differ` and add a warning.
  - Retained sources are byte-identical and hash-checked before writing.
  - A source above the file limit, or any source when retention is off, is recorded with a `retention_note` instead.
  - `test_bundle_pins_inputs_hashes_files_and_retains_the_source`, `test_mixed_retrieval_times_are_flagged_and_mismatched_sources_rejected`, `test_budgets_reject_oversized_files_bundles_and_unsafe_names`.
- **A stdio client retrieves a real binary artifact; no local path is presented.**
  - A real stdio MCP session calls `chart_tuik_data(save=true)` and reads every linked file with `resources/read`.
  - Each read matches the link's MIME type, size and SHA-256.
  - The PNG equals the returned image, and the manifest reads as JSON.
  - The result text holds no storage path and stays under 6,000 characters.
  - `test_stdio_client_reads_binary_artifacts_including_a_large_file`.
- **Expiry, eviction, restart and unavailable snapshots are actionable; nothing is regenerated.**
  - Expired → `expired` with the expiry time; evicted or unknown → `not_found`; tampered → `corrupted`. Each message says a new save creates a new artifact.
  - A new process serves an older bundle.
  - `test_total_budget_evicts_the_oldest_and_expiry_is_actionable`, `test_restart_reads_the_same_bundle_and_tampering_is_detected`.
- **Budgets; traversal, symlinks and unsafe names.**
  - Total bytes (oldest evicted), file size, files per bundle and lifetime are budgeted. Concurrent jobs are bounded (four saves with `max_jobs=1` never overlap).
  - Rejected: `..`, `/`, hidden or reserved names, malformed IDs and URIs, symlinked files, symlinked bundles and a symlinked root.
  - `test_ids_paths_and_symlinks_cannot_escape_the_root`, `test_concurrent_jobs_are_bounded_and_staging_is_never_swept`.
- **Large files and clients without resource-link display.**
  - A 6 MiB binary written by an earlier process is read back byte-for-byte over stdio.
  - UTF-8 text returns as text; a cp1254 CSV stays a byte-exact blob.
  - `tuik-mcp-artifacts list/show/export` exports a verified bundle without overwriting (`test_cli_lists_shows_and_exports_without_overwriting`).
- **Provenance on outputs.**
  - The PNG draws the source page and retrieval date (existing behaviour).
  - `README.txt` repeats the citation and warnings; `manifest.json` carries the full record.
  - The CSV has no embedded citation, a documented limit of this slice; the Office/PDF renderers (#92–#94) will carry visible citations per sheet/slide/page.

`test_saved_chart_bundles_png_plotted_values_notes_and_source` checks that the plotted CSV matches the chart summary (last point `7.8`) and that the input hash equals the chart's `snapshot_id`.
